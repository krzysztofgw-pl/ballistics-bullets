# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues.

- Preferred: use GitHub private vulnerability reporting. Open the **Security** tab of this repository and choose **Report a vulnerability**.
- Or email **kgwlabs@interia.com** with "Security" in the subject.

Please include what is affected (file, tool or workflow), steps to reproduce and the impact you expect. We aim to reply within 7 days and will tell you when a fix is released. Credit is given in the release notes unless you prefer otherwise.

## Supported versions

Only the `main` branch and the published bundle are supported.
